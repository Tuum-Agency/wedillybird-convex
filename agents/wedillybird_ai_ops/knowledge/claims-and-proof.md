# Claims And Proof

Public claims require proof before publication.

Allowed product facts from the repo:

- Wedillybird is a wedding organization SaaS.
- It supports WhatsApp invitations.
- It supports RSVP tracking.
- It supports QR check-in.
- It supports a shared photo gallery.
- The public copy targets France and francophone Africa.

Claims that need explicit verification before reuse:

- usage counts;
- satisfaction scores;
- open rates;
- performance numbers;
- load times;
- "tested with grandparents" style claims;
- comparisons against email or competitors;
- testimonials.

Rule for agents:

- If a claim has no source, mark it as `needs proof`.
- If a claim is not needed, remove it instead of making it softer.
